# To-Do App  

A simple and responsive **To-Do List Application** built with **HTML, Tailwind CSS, and JavaScript**.  
This app helps you manage daily tasks with features like adding, editing, deleting, marking as complete, setting priority levels, searching tasks, and dark mode support.  
All tasks are stored in **LocalStorage**, so they persist even after refreshing the page.  

---

## ✨ Features  

### Core Features  
- ➕ **Add Tasks** with text input.  
- ✅ **Mark Tasks as Completed** by clicking on them.  
- ❌ **Delete Tasks** with a single click.  
- ✏️ **Edit Tasks** by double-clicking.  
- 🔍 **Search Tasks** in real time.  

### Additional Features  
- 🌗 **Dark Mode Toggle** for better user experience.  
- 🎯 **Task Priority Levels** (Low, Medium, High).  
- 💾 **LocalStorage Support** (tasks are saved locally).  

---

## 🛠️ Technologies Used  

- **HTML5**  
- **Tailwind CSS** (CDN version)  
- **JavaScript (ES6)**  
- **LocalStorage API**
